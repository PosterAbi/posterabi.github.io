# Sisselogimine

Ligipääsuandmed Admin Paneelile ja kassale.

## Ülevaade

| Süsteem | Kasutajanimi | Parool / PIN | Unustasin? |
|---------|-------------|--------------|-------------|
| **Admin Paneel** | Töö e-posti aadress | Aktiveerimise parool | Vajuta **"Unustasin parooli"** admin paneelis. |
| **Kassa (POS)** | Kassa kasutajanimi | Kassa parool | Küsi administraatorilt |
| **Kassa PIN** | — | Unikaalne PIN igale töötajale | Küsi administraatorilt |

## Admin Paneeli sisselogimine

1. Ava Admin Paneeli leht **asutus.joinposter.com**
2. Sisesta töö **e-posti aadress**
3. Sisesta **parool**, mille seadsid kasutaja aktiveerimisel

## Kassa sisselogimine

1. Ava **Kassa**
2. Sisesta **kasutajanimi ja parool**
   - Ei küsi alati, kuid kui ei mäleta siis küsida administraatorilt.
3. Vali töötaja ja sisesta **PIN-kood**

:::warning Unustasid PIN-koodi?
Küsige administraatorilt!
:::
