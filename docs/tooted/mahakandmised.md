## Sammud

**Tee:** `Admin Paneel` → `Ladu` → `Mahakandmised` → `Lisa`

1. Ava **Admin Paneel** → **Ladu** → **Mahakandmised** → **Lisa**
2. Vali kuupäev ja kellaaeg
3. Vali oma asukohale vastav **ladu**
4. Vali mahakandmise põhjus — vajadusel lisa kommentaar
5. Vali toode, sisesta kogus ja vajuta **„Salvesta"**
