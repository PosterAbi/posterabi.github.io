## Sammud

**Tee:** `Admin Paneel` → `Menüü` → `Kaubad`

1. Ava **Admin Paneel**
2. Vasak menüü → **Menüü** → **Kaubad**
3. Klõpsa **„Lisa"** uue toote lisamiseks _või_ **„Toim."** olemasoleva muutmiseks
4. Täida kõik nõutud väljad
   - Soovitatav on lisada toodetele ja kategooriatele pildid
5. Märgi valik **„Erinevad hinnad teistele asukohtadele ja tellimiskohtadele"**
6. Sisesta oma kohvikule õige hind **"Kokku"** lahtirsse.
7. Klõpsa **Salvesta**

:::warning Tähelepanu
**Uus toode:** Märgi „Näita" ainult oma kohvikule.

**Muutmisel:** Ära muuda teiste kohvikute „Näita" märget ega hinda.
:::
