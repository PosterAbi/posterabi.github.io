# Raha algseisu seadmine

Kontode esialgse saldo sisestamine enne kassasüsteemi kasutuselevõttu.

## Sammud

**Tee:** `Admin Paneel` → `Finantsid` → `Kontod`

1. Ava **Admin Paneel** → **Finantsid** → **Kontod**
2. Vali õige konto ja vajuta real **„Toim"**
3. Sisesta konto esialgne saldo

## Kontode tähendused

| Konto | Tähendus |
|-------|----------|
| **Sularaha** | Sularahakassas olev summa |
| **Pank** | Kohviku pangakonto saldo |
| **Seif** | Sularahakassast välja võetud raha, mis ootab panka viimist |
