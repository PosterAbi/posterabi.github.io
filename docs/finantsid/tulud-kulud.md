Tulude, kulude ja makseviisside ülevaade asutuse või töötaja kaupa.

## Tulude ja kulude jälgimine

**Tee:** `Admin Paneel` → `Statistika` → `Tšekid`

1. Ava **Admin Paneel** → **Statistika** → **Tšekid**
2. Filtreeri **asutuse** või **töötaja** järgi ning vali ajaperiood
3. Tabeli all kuvatakse perioodi kokkuvõte:
   - Kogu tulu
   - Milliste vahenditega ja kui palju makstud on
   - Allahindluste summa
   - Kasum
4. Vajuta **„Üksikasjad"** tšeki real üksiktšeki vaatamiseks

---

## Makseviisid päeva kaupa

**Tee:** `Admin Paneel` → `Statistika` → `Makseviisid`

1. Ava **Admin Paneel** → **Statistika** → **Makseviisid**
2. Vali asutus ja ajaperiood — näed päevade kaupa:
   - Tšekkide arv
   - Sularahas / kaardiga / kokku makstud
