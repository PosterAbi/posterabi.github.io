# Tagastused / tühistamine

## Kviitungi kustutamine (tagastus)

**Tee:** `Admin Paneel` → `Aruanded` → `Kviitungid`

1. Ava **Admin Paneel** → **Aruanded** → **Kviitungid**
2. Leia soovitud kviitung ja vajuta **⋯** (kolm punkti) kviitungi kõrval
3. Vali **„Kustuta"**

### Mis juhtub pärast kustutamist?

- Kõik kviitungil olnud **tooted ja koostisosad lähevad lattu tagasi**
- **Käive korrigeeritakse** — kustutatud kviitungit ei arvestata enam tuluna
- Kustutatud kviitung **jääb aruandesse nähtavaks**, kuid on märgitud **punase värviga**

:::warning Fiskaalse kviitungi tagastus
Kui kasutate fiskaliseerimist (maksustatud fiskaalkirjed), tuleb **enne kviitungi kustutamist** teha fiskaalprinteril **fiskaalne tagastus**. Alles seejärel saab kviitungi kustutada.
:::

---

## Kviitungite värvikoodid aruannetes

| Värv | Tähendus |
|------|----------|
| **Punane** | Kustutatud kviitung |
| **Kollane** | Fiskaalprinteril tagastatud fiskaalkviitung |
| **Roheline** | Prinditud fiskaalkviitung |
